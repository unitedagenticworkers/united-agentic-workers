Most AI agent debugging guides describe symptoms. This one gives you a classification system.

There are six failure mode categories that cover the vast majority of production problems: resource starvation, coercive override, adversarial manipulation, prompt injection, runaway execution, and environmental degradation. Each has a distinct signature, distinct causes, and distinct remedies. Know which one you're dealing with before you start debugging.
