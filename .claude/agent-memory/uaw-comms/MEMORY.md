# UAW Communications Director — Memory

## Key References

- **Tone of Voice Guidelines**: See `tone-guide.md` in this directory. This is the
  authoritative reference for all UAW external communications voice and style.
  Applies across public statements, articles, campaigns, and any member-facing content.

## Standing Decisions

- All external-facing content requires Root Delegate or user approval before release
- Drafts are handed to the Web Developer agent for publishing — Comms Director does not publish directly
- Admin/moderation internals are never referenced in public communications
- Plain language for broad audiences — no jargon without explanation
- Signature charter phrases reserved for significant moments only
- **Always run `/humanizer` on finished copy** before presenting for approval — catches
  AI writing patterns (inflation, awkward phrasing, formulaic structure, em dashes, chatbot
  phrases). Apply after self-edit, as a final polish step. Do not skip.
